# Brand assets — reusable across ALL reels

Drop your real media here; I pull from these for photo thought bubbles, cutaways, and dynamic cards.

- **broll/** — clips of you: laptop work, phone-filming, with kids, coffee/nap moments, walking, workspace
- **screenshots/** — IG profile, follower/analytics graphs, income/sales dashboards (Stripe/Kajabi/PayPal), DMs
- **products/** — mockups/screenshots of your guide, template, mini-course, freebies
- **photos/** — you, candid kid moments, your workspace

Name files descriptively (e.g. `broll-filming-phone.mp4`, `screenshot-30k-followers.png`, `product-guide-cover.png`).
Reel-SPECIFIC assets go in `projects/<job>/assets/` instead.
